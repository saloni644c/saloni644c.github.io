Knee MRI abnormality detection from radiology reports

Kaggle RSNA challenge, ongoing

A weakly supervised pipeline for 12 knee findings. MedGemma-4B reads more than 4,400 multilingual radiology reports (9 languages) and returns a label, a confidence score and a verbatim evidence quote for each finding, so every label can be traced back to the text.

  • Checked against 58 expert-labelled reports. Macro AUC across all 12 findings is currently 0.78 and still improving; the ACL label alone reaches 0.944.
  • The imaging model is an MRNet-style multi-view CNN (pretrained AlexNet per MRI plane, slice-wise max-pooling) trained on the LLM-generated labels instead of expert annotations.

PyTorch, MedGemma, multi-label classification
